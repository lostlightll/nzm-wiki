# TextStyle

包裹文字使其变色，children 为 `React.ReactNode`。

## 颜色

`<Red>`, `<Yellow>`, `<Green>`, `<Grey>`, `<Orange>`, `<Brown>`, `<Blue>`, `<Purple>`, `<Pink>`

## 元素

`<Fire>`, `<Ice>`, `<Shock>`, `<Corrosive>`, `<Kinetic>`

## 高亮

`<Highlight color="sunny">文字</Highlight>`

color 可选：sunny, sky, rose, lime, violet, orange

## 示例

```mdx
伤害提升 <Yellow>50%</Yellow>，持续 <Red>10</Red> 秒
<Fire>灼烧</Fire> 效果
<Highlight color="rose">重要信息</Highlight>
```
