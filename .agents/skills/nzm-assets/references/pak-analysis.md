# 按需分析现有补丁包

目标体验与 FModel 中打开一个包相同：查看这个包自己的条目，选一个资产，查看它相对前版的变化。现有文件直接读取；内存只装载索引、当前资产和必要依赖；磁盘仅在明确需要导出时写入产物。

## 硬性边界

- 严格禁止复制整个 `.pak`，禁止通过硬链接、符号链接隔离容器或建立第二套游戏目录。包小、临时使用、缓存、校验、留证和工具能力不足都不是例外。
- 直接读取原位置的容器；不得把整包读入内存作为复制的替代方案，也不得全量解包或批量导出候选版本来绕过限制。
- 需要保存时，只导出明确选定的资产及其必要配套文件（如 `.uasset/.uexp/.ubulk`）或少量分析结果。允许导出资产不等于允许复制其所在的 `.pak`。
- 工具无法原地读取或指定版本时，报告缺少的能力，或在已授权的源码任务中补接口；不得退回复制或链接容器的流程。

## 命令入口

从项目根目录调用 `.agents/skills/nzm-assets/scripts/Invoke-Nzm.ps1`：

```powershell
$tool = '.agents/skills/nzm-assets/scripts/Invoke-Nzm.ps1'
& $tool -Command containers -Query '4519726' -Limit 20
& $tool -Command list -Container 'P_1.0.50.485.0_R_4519726_P.pak' -Limit 20
& $tool -Command diff -Container 'P_1.0.50.485.0_R_4519726_P.pak' -Asset 'NZM/Content/Attributes/AutoGenerate/numerical_modifier_config.uasset' -MaxDifferences 20
```

`-Against <容器名或准确绝对路径>` 可指定旧容器；省略时由 CLI 选前一可用版本。`-Offset` / `-Limit` 用于容器和条目分页；`-MaxDifferences` / `-MaxDepth` / `-MaxNodes` 限制差异输出和遍历。显式路径应来自已定位的容器，不把本机安装路径写入 skill 默认值。

## 默认流程

1. 定位用户指定的现有 pak。使用已有 profile 或显式路径，不复制游戏配置、不新建 AES key。文件名不唯一时列出候选，不能任取一个。
2. 按容器列条目，先取一页（通常 20 条），返回条目总数和类型概况。`.uasset` 与 `.uexp` 属于同一资产，不能按两个功能更新计数。不要用全局合并搜索冒充目标包目录。
3. 先看与问题有关的数据表或配置。一次比较一个资产；由容器优先级寻找该路径的前一可用版本，记录两边的实际容器。前版可能在更早的补丁或基础包中，不一定在文件名最接近的 pak 中。
4. 只返回有变化的行/字段及前后值，先给变更总数和前 20 项。大量变化按资产或字段筛选后继续，不将整张表或所有原始字节码送入上下文。为得到差异而完整解码一个被选中的资产可以接受，不预解析其余资产。
5. 对 Lua、蓝图或其他非表资产，概览阶段只标记“内容变化/未变化/无法判断”及涉及模块。用户追问 Lua 具体行为时按 [Lua 分析流程](lua-analysis.md)展开变化函数；Blueprint Kismet 使用 `nzm-uasset` 的专项参考。

## 前版与证据

- 前版依据同一路径的容器优先级，而非文件修改时间或目录遍历顺序。最高候选同优先级时说明歧义，必要时明确指定比较容器。
- 主包与配套文件来自一致版本；依赖解析不能用新版本覆盖旧资产语义。工具无法保证时明确限制，不能把混合版本比较称为真实前后差异。
- `包内包含`、`二进制变化`、`字段变化`、`运行行为变化`分别表述。表描述与 Numerical 冲突仍按项目数值规范处理。
- 证据引用现有 pak 名、资产路径、行/字段即可；不以“留证”为由默认导出整份 JSON。复制包或创建容器快照树始终受上述禁令约束。

## 扩展与停止

当前页已解释用户关注点就结束。仅在问题需要时翻页、追引用或解析函数，不默认要求把每一项变化还原成机制。

只读 CLI 缺少按容器读取或指定版本对比时，走已授权的 FModel 源码任务补接口；Wiki 侧不临时复制/链接 pak，也不通过私有 DLL 反射重新实现容器选择。显式导出仅保存所需资产，人工报告仅在用户需要时创建。用户已删除的历史产物不恢复。
