| 类型       | 僵尸猎场 | 塔防 | 机甲PVP |
| :--        | :--:     | :--: | :--:    |
| 角色攻击力 | 500      | 400  | -       |
| 角色技能力 | 3000     | -    | -       |


| 伤害颜色              | 描述                             |
| -                     | -                                |
| 白色                  | 普通命中身体, 武器直伤           |
| <Yellow>黄色</Yellow> | 命中弱点，弱点倍率取决于**武器** |
| <Orange>橙色</Orange> | 非弱点暴击，基础暴击伤害为 150%  |
| <Red>红色</Red>       | 弱点暴击                         |


> 武器伤害计算
> 
> 基础面板伤害 × (1 + 猎场额外攻击力) × (弱点倍率 **累乘**) × (暴击倍率 **累加**) × 额外增益累乘(武器插件增伤, 技能增伤、近战武器、折磨 BUFF、感电增伤等)
> 
> *<Grey>个别插件需要单独讨论</Grey>*
