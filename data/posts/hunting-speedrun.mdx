## 道具

| 道具 | 效果 |
| :--- | :--- |
| 意念干扰 | 移动方向相反 |
| 时空闪电 | 类似BOSS的技能指示器显示一个红圈，对对方玩家造成 **200** 伤害 |
| 凌空泼墨 | 向对方扔墨水，屏幕中央被染黑 |
| 对方减速 | 降低对方移动速度 |
| 团队护盾 | 团队免疫伤害5秒 |
| 单人护盾 | 自己免疫伤害5秒 |
| 禁用复活币 | 15秒内禁止对方使用复活币 |
