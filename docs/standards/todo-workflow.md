# TODOList 协作规范

> 状态：active

## 标准格式

```md
**TODO(@执行者): 任务标题**

**TODO(@执行者1, @执行者2): 多人任务标题**

- 状态：待确认
- 目标：说明这项任务最终要解决什么问题
- 工作项：
  - [ ] 可独立检查和完成的事项
- 验收标准：说明完成后如何确认结果正确
- 结果：完成时补充页面、提交或数据来源
```

执行者尚未确定时统一写 `TODO(待认领)`，不要猜测账号。多人共同执行时，在括号内按分工顺序列出所有执行者，并在正文中增加“分工”字段。

## 状态流转

1. **待确认**：创建 TODO，补齐目标、工作项和验收标准。
2. **待处理**：执行者确认接手，任务正式进入队列。
3. **进行中**：执行者开始调查或修改，并及时勾选已完成的工作项。
4. **待验收**：执行者补充结果和验证依据，等待维护者检查。
5. **已完成**：维护者确认达到验收标准；保留结果记录，不直接删除任务。

无法继续的任务标记为“已阻塞”并写明原因；不再需要的任务标记为“已取消”并说明决定人和原因。
